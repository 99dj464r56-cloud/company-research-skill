# 自查清单（交付前必做）

**原则（Superpowers verification-before-completion）：没有本轮新鲜证据，不得声称「好了／整齐／通过」。**

## A. 自动检查
```bash
python3 "$SKILL_ROOT/scripts/pdf_audit.py" 报告.pdf [禁用词…]
```
查：文字靠边或越界；末行只剩 1–3 字的孤行（正文必须改写消除，不要缩字号；表格单元格短行可忽略）；`未取得`／`…`／禁用词计数；页边墨迹。文字重叠靠看图（Chrome Type3 字框不可靠）。

## B. 图表数据校验（不靠眼睛）
图由脚本从原始序列生成，并输出「图用数据」：
1. 零线基线正确；正负柱与符号一致
2. 柱数／点数 = 数据行数
3. 高低点、转正点的年份与数值取自数据，不是手写
4. 各国页坐标范围、字号、图例位置一致
5. 标注框不遮曲线／柱／其他标注，不出图框
6. 图例颜色符合全篇规则
7. 横轴时点口径一致（年末／3 月末写明；基线如「2006 年 3 月末＝100」）

## C. 版面逐页看图
`pdftoppm` 100–150 dpi，不要只看缩略图。查：同类页卡片等宽等高；左右栏顶底对齐；图左右边距对齐；上文下图比例；页脚不压内容；表格行高均匀；附件网址不溢出或撞列；孤行／寡行；页眉页脚名称；页码引用与实际页一致。逐页打勾；有一处不整齐 → 改 → 重导 → 再从头看。

## D. 一致性
币别、口径、颜色、术语、基线标签全篇一致；每个数字能在底表或来源页找到；改过的数字，所有引用页一并更新；PDF sha256 与执行者报告一致；页数正确。
