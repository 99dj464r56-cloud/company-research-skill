# 自查清单（交付前必做）

原则：没有本轮的新鲜证据，就不得说「好了」「整齐」「通过」。

## A. 自动检查

先跑研究稿检查，再跑排版两道门禁，全部通过才可进入看图。

```bash
python3 "$SKILL_ROOT/scripts/pdf_audit.py" 报告.pdf [本报告禁用词…]
python3 "$SKILL_ROOT/scripts/终版排版验收.py" 报告.pdf [附录页码.json] [--expect-pages N]
python3 "$SKILL_ROOT/scripts/检测裸数字.py" <SVG目录>
```

`pdf_audit.py` 检查文字靠边或越界、末行只剩 1–3 字的孤行、占位符（未取得、…、TODO 等）和禁用词的计数，以及页边墨迹。脚本不查文字重叠（Chrome 的 Type3 字框不可靠），重叠要靠看图。报告专用的禁用词（如已弃用的旧称）作为参数传入，不写进脚本。`--expect-pages` 仅在报告已约定总页数时使用。如果已知某几条遗留警告可以接受，要在交付说明里逐条列出。

**幅面确认**：逐页核对 PDF 页面几何与约定幅面一致（A4 直面＝595×842pt／210×297mm，全书统一；横面则 841×595pt）。约定 A4 却导出 A3，或全书页面尺寸不一，都是交付级错误。导出自查用 `MediaBox` 读取全部页面。

## B. 图表数据校验

- 图由脚本从原始序列生成，并输出「图用数据」。
- 零线基线要对，正负柱和符号一致，柱数和点数等于数据行数。
- 高低点、转正点、补回点的年份和数值取自数据。
- 各案例页的坐标范围、字号、图例位置一致；标注不遮挡曲线，也不出图框。
- 横轴必须覆盖观察窗和脚注写到的全部时点，口径写明（年末、财年、基期＝100）。

## C. 逐页看图

用 `pdftoppm` 以 100–150 dpi 逐页放大看，不能只看缩略图。检查：卡片等宽等高、栏目对齐、页脚不压内容、表格行高均匀、网址不溢出、无孤行、页眉页脚名称正确、页码引用和实际页一致；文字与线柱不重叠、不截断、横轴标签不挤成一团。逐页打勾；有一处不整齐就改、重导，再从头看。

## D. 颜色与符号清单

- 全文搜评价色（红、绿、黄）的 CSS 类和内联色，逐条判断是借鉴/评价还是误用到了图表系列。列清单：页｜文字｜颜色｜判断｜改法。
- 核对图表方向色与指标色：个贷深灰黑、消费贷深绿、房贷深棕、经营贷琥珀橙；单系列增减为蓝增红减。颜色词必须与线柱一致。
- 全文搜 ▲▼→，逐处判断是幅度还是水平值，检查颜色、同字重，以及三角后的数字是否同色。

## E. 文字扫描

- 外文文字原样写法（读者不认的文字）计数为 0。
- 版本痕迹词计数为 0（统计含义的「新增」除外）。
- 「见第 N 页」类指向只用于附件，并且不代替关键事实。
- 报告专用的禁用词计数为 0。

## F. 一致性

币别、口径、颜色、术语和基线标签全篇一致；每个数字都能在底表或来源附件里找到；改过的数字，所有引用页一起更新；编号连续，没有悬空引用；**图引用全部解析**（每张图有出处，每处引用有对应图，无断号）；PDF 的 sha256 与执行者报告的一致；页数正确、幅面与约定一致。
