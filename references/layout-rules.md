# 版式、颜色、符号与数字

## 页面
- A3 横版，白底黑字，可打印。HTML 是母版，用 headless Chrome 导出 PDF。
- 每页都有页眉（部分名｜节名）、页脚（来源）和页码。
- 同类页的卡片等宽等高，左右栏顶底对齐，上文下图比例全篇一致。
- **不缩字号**。版面挤时，改写句子、调整间距或分页；版面空时，调整间距填满，不堆字。只有用户对某一页明确同意，才可以在那一页缩字，交付说明里要写明。
- 不留孤行（末行只剩一两个字）：改写句子消除，不靠缩字。
- 附件网址用纯文本，不做超链接，不得溢出或撞列。

## 颜色（全篇只有三种语义色）
| 用途 | 颜色 |
|---|---|
| 好／改善／值得借鉴 | 绿 `#1E8E4E` |
| 接近坏／预警／自查要点 | 黄 `#9A6700` |
| 坏／恶化／避免踩坑 | 红 `#C62828` |
| 引用号 [n] | 紫色斜体 `#5b3fd0`，约 0.8em（唯一例外） |
- 其余一律黑色，强调用黑色粗体。标题、对象名、栏目名、中性指标词（余额、新增等）、图表系列、表头都不用红、绿、黄。
- 图表用黑色实线、虚线和标记区分系列；柱子只按评价上色（如净增、净减、仍增但低于阈值），并在图例里说明这些颜色是不是表示好坏。
- 颜色按「结果对被描述对象是好还是坏」来定，不看数字的方向。
- 用户没有点名的语义色和符号，不得擅自改；拿不准时对照上一版保持原样。

## 三角形与箭头
- **▲▼只表示变化幅度**：数字本身就是变化量或变化率，要写明比较的两个时点。三角只有红、绿两色；紧跟在三角后的幅度数字和三角同色。
- **水平值用「A→B」**：两个数字都是黑色，字重一致，只有箭头按好坏上红色或绿色。终点值前面不放三角。
- 纯属研究对象本身的中性升降，不画三角，用黑字写「下降约 X%」。日期区间用「至」或「–」。
- 每页图例统一写：「▲▼＝变化幅度　→＝由 A 变到 B　红＝恶化　绿＝改善」。
- 先确认 PDF 字体能渲染这些符号。

## 币种与数字
- 币种分层：正文和汇总用读者的币种（第 1 页的金额要写明币种名）；附件保留原币，方便对原表核对；折算方法和汇率来源写在口径附件里。已经写了读者币种的，就不再并列原币。
- 折算用事件所属期间的官方平均汇率，只用来感知量级；折算年份不同的数不相除。外币图轴不强行换算。
- 金额不带不必要的小数位；比例默认保留一位小数；附件可以写精确值。
- 币别永远写明；幅度要说清是百分比还是百分点。

## 指向与引用
- 关键事实就地写清，不用「见第 N 页」代替。
- 指向附件用【附件 X（第 N 页）】；附件分页时写「第 N–M 页」。改了页数，所有页码引用、第 1 页页码地图和每页页码要一起改。
- 计算只放附件，正文只写结果。

## 唯一最终版
- 正文、页脚、图例里都不放「新增」徽标、「更新」「本次补充」「较上版」或版本号。统计含义的「新增」要保留。
- 草稿阶段可以写「待补」，文件名可以带版本号；用户宣布定稿时全部清掉。
