# 汇报模板（填空骨架）

尖括号是占位符，例如 <主题>、<案例A>、<口径简称>。骨架只规定位置和句式，内容从本课题自己的证据里来。

## 1. 第 1 页摘要
```
<主题：对象＋问题，一句话>

┌<案例A> ▼<幅度>%┐ ┌<案例B> ▼<幅度>%┐ ┌<案例C> ▼<幅度>%┐ ┌<对照对象> 对照 ▼<幅度>%┐
│<口径简称>：<本案例对应的序列> [n]│                    │对象：<序列>  期间：<起>至<止>│
│<起始年>年起持续 <N> 年<变化>，期间<规模>约 <读者币种> <X>；<回到/仅为 某时点水平>│
注：<口径简称>＝<一句定义>。幅度按<算法>计算；各数的产品、期间不同，不作横向排名；<币种>金额按【附件 X】折算。

┃<案例A> 影响（<期间>） <一句结论>        ┃<案例B> 影响 …   ┃<案例C> 影响 …
┃•<指标> <A>→<B>（<起>至<止>）[n]
┃•<事实＋数字> [n]
┃<案例A> 应对（<期间>） <一句结论>        ┃…
┃•<时点>：<谁做了什么，规模> [n]

借鉴目录（<一行适用边界说明>）
[绿＝值得借鉴 <k>条｜第 X 页] 绿 1 <短标题> 绿 2 …
[红＝避免踩坑 <k>条｜第 X 页] 红 1 <短标题> …
[黄＝自查要点 <k>条｜第 Y 页] 黄 1 <短标题> …
页脚：主汇报第 1–M 页（第 X–Y 页＝借鉴汇总）｜【附件第 M+1–Z 页】                     1
```

## 2. 第一部分 案例页
```
页眉：第一部分 发生了什么                                         <节号> <案例>
<节号> <案例>：<进入原因>；<走出方式>；<现状>
┌走入─────────────────────┐ ┌走出─────────────────────┐
│关键：<一句>                │ │关键：<一句>                │
│发生了什么：<数据事实> [n]   │ │发生了什么：<转正/补回时点> [n] │
│为何走入：•<原因1> •<原因2>  │ │为何走出：•<措施或条件，只列时点> │
└──────────────────────┘ └──────────────────────┘
口径：左图<水平序列>（<基期>＝100）；右图<流量序列>。▲▼＝变化幅度 →＝由 A 变到 B 红＝恶化 绿＝改善
[左图：指数折线，黑线/虚线区分系列，标注低点/补回点]  [右图：柱状，红/绿/黄柱按图例，虚线框＝连续减少期间]
图例：<柱色含义>　数据：<来源>；底表见【附件 X（第 N 页）】                         <页码>
```

## 3. 第二部分 案例页
```
<节号> <案例>：<应对先后与结果，一句话>
政策（政府与监管）                    影响
•<时点>：<措施，规模> [n]             •<主体1>：<指标 A→B，规模> [n]
•…                                    •<主体2>：…
对策：谁做了什么｜可观察结果［｜机构结局］
| 主体 | 做了什么 | 可观察结果 | 机构结局（存续/并入/退出/—） |
注：<币种>为按事件年度汇率折算的约数，仅供感知量级。借鉴集中在第 X–Y 页。
来源：<机构 日期；…>；链接见【附件 X】                                              <页码>
```

## 4. 借鉴卡
**绿卡**
```
绿 <n> <标题>
<一句做法：谁、做什么、怎样记录或公开>
```
**红卡**
```
红 <n> <标题>                       关键词：<4–8 字>
<行动句：从读者视角写，要防什么、事先做什么>
依据 <一行量化事实，约 40–60 字，黑字> [n]
与黄栏区别 黄 <m> 是<机构自查什么>；红 <n> 是<决策层管什么>。
```
**黄条**（按主题分组）
```
<主题>（黄 a–b）
黄 <n> <标题> <可核对的问句：是否……，并注明……？>
```
汇总页页脚：事实与来源见【附件 X、Y】；借鉴的底稿见【附件 证据表（第 N 页）】。

## 5. 附件表头
| 附件 | 列 |
|---|---|
| 借鉴证据表 | 编号（绿-01…）｜标题｜原币关键｜限定｜本报告页｜出处编号 |
| 来源与口径登记 | 编号｜结论／读数｜来源与版本｜原始文件／字段｜计算方法｜状态（✓原表已取得／✓原文已核／○官方来源／○转引） |
| 案例与措施来源 | 编号（接续）｜读数｜来源与日期｜链接 |
| 时间线 | 阶段｜时间｜持续｜数据表现｜同期事件／结果 |
| 逐年数据 | 年｜<案例>序列（原币，单位写在表头） |
| 口径底表 | 年｜余额｜指数（基期＝100）；其他引用读数：读数｜数值｜时点｜来源 |
| 口径与名称对照 | 统一名称｜读者基准定义（单位、时点）｜各案例对应名称与处理 |
| 计算方法 | 规则名｜回答什么问题｜方法（单位、幅度、取整、折算、颜色、解释边界） |
| 计算说明 | 指标｜起止｜期初｜期末｜变化｜计算式｜结果｜对应页 |

附件页的颜色说明、编号说明只在该附件第一页出现一次；续页只写页码、标题和「续」。
