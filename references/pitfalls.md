# 踩坑清单

- 图的基线、柱子和数据对不上；标注数字是手写的。
- 加了网址后，附件页溢出或撞列。
- 页脚过长，压住了内容。
- 数据截止日过旧；序列更新后，没有把所有引用页一起改。
- 各案例口径不一致；对照对象和案例用的不是同一套口径。
- 规则日期张冠李戴（要核对文件本身）。
- 统计断点没注明，就说「补回」。
- 人均或比率没写主体和分母；金额没写币别。
- 原币是用读者币种按汇率倒推出来的。
- 对照对象的情况混进了「影响」。
- 第 1 页、案例页和借鉴汇总三者重复叙述。
- 颜色前后不一致；中性词用了红、绿、黄；数字被套上颜色类。
- 「A→B」的终点值前面放了▲▼。
- 有孤行时缩字号（应该改写）。
- 证据弱就删内容，或加上免责小字。
- 正文里留下版本痕迹。
- 改了页数或附件顺序，但编号、引用、页码地图没有一起改。
- 把用户对某一份报告的具体写法当成通用规则写进 skill。
