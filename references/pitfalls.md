# 踩坑清单

- 图的基线、柱子和数据对不上；标注数字是手写的。
- 加了网址后，附件页溢出或撞列。
- 页脚过长，压住了内容。
- 数据截止日过旧；序列更新后，没有把所有引用页一起改。
- 各案例口径不一致；对照对象和案例用的不是同一套口径。
- 规则日期张冠李戴（要核对文件本身）。
- 统计断点没注明，就说「补回」。
- 人均或比率没写主体和分母；金额没写币别。
- 原币是用读者币种按汇率倒推出来的。
- 对照对象的情况混进了「影响」。
- 第 1 页、案例页和借鉴汇总三者重复叙述。
- 颜色前后不一致；把评价色用到图表系列上，或把图表指标色当成借鉴红绿黄。
- 另写一套排版规则，或只改其中一份、另一份过期。
- 把成品里的拥挤、截断、重叠当作排版规范。
- 多系列图里房贷与个贷共用黑色，或沿用已废弃的「③层蓝线、消费贷深蓝」。
- 「A→B」的终点值前面放了▲▼。
- 有孤行时缩字号（应该改写）。
- 证据弱就删内容，或加上免责小字。
- 正文里留下版本痕迹。
- 改了页数或附件顺序，但编号、引用、页码地图没有一起改。
- 把用户对某一份报告的具体写法当成通用规则写进 skill。
- 题名把含层级的概念并列（如「个贷与消费贷」——个贷已含消费贷）；多地区并列却没有口径对照表作证。
- 摘要或正文里残留日文汉字（如「貸金業法」）当简体交付；外来法规名称要核对原始文献用字再落简体。
- 导出 PDF 后漏跑页码盖章脚本，整本无页码；或约定了总页数却没有用 `--expect-pages` 两遍法收敛。
- 压缩空白只压了正文，摘要和目录仍摊成三四页，前部大片空白没人管。
- 验收共享上传时看文件列表的 size 字段（会延迟显示旧值）或手抄下载 URL（破坏签名报 XML 错误）；要下载回读、比对 MD5。
