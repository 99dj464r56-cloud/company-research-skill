# 固定页面架构（A3 横版，约 17–19 页，白底可打印）

## 第 1 页 = 自足完整摘要
- 标题；各对象大红负增长数字 + 对象、期间。
- 「影响」与「应对措施」同一风格，逐对象一两行。
- 只放一个小字号「当前位置」对照卡（本方，约 80% 宽；只作对照、不评有效性、不预测）；不在「影响」里写本方。
- 不重复后面的走入／走出；不写「见第 X 页」。
- 下半页影响／应对放大，占一半以上。第 1 页要能在 30 秒内读懂，结论放最前。

## 第一部分「发生了什么事」
- 每个对象一页：上=走入／走出（为什么进入、关键；为什么走出、关键；白话，约半页）；中=口径一行；下=自画双趋势图（半页以内）。
- **不写借鉴**。页眉：「第一部分 发生了什么事」。

## 第二部分「影响、对策与借鉴」
- 每对象一节（内容确实放不下才用两页）：影响；对策按主体拆（监管／政府、银行、企业）；每条有案例、是否见效、判断标签（判断落在可观察结果 + 来源）。
- 末节「借鉴汇总」1–2 页：按「值得借鉴／避免踩坑／自查要点」分类（不按国别）；类内按主体拆；每条标对象标签和页码。
- **借鉴只出现在这一节**。

## 命名
- 「主汇报」＝第一部分＋第二部分；第一部分本身不叫主汇报。
- 页眉页脚统一用这些名字；首页页脚写页码地图。

## 第三部分 附件（顺序固定）
时间线 → 计算说明（与时间线相连）→ 总体逐年数据与分对象数据（紧邻成对）→ 口径底表 → 口径与名称对照 → 来源与口径登记 → 个案与措施来源。

改顺序必须同步改编号、正文引用、页脚与页码。长序列放附件，正文只写一句。

## 版式
标题简洁，不写「董事会版」，不留版本痕迹；文件名带日期；uploads 只保留一份报告 PDF。
