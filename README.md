# 公司课题研究

本仓库 https://github.com/99dj464r56-cloud/company-research-skill 是「公司课题研究」的唯一公开标准：研究框架与排版合并在这一份 skill 中。不要另用「排版规范」或其它平行模板。

- 先读 `SKILL.md`
- 排版细则见 `references/layout-rules.md`
- 打印以 A4 为基准（默认 A4 直面；A4 横面、A3 横面仅用户明确指定时使用）
- 交付件为三件套：MD 母稿、HTML 母版（图片 base64 内嵌、零外部引用）、PDF 打印版
- 交稿前必须跑 `scripts/` 里的自查和两道排版门禁：`pdf_audit.py`、`终版排版验收.py`、`检测裸数字.py`
- 版本日期：2026-11-19。更新只改这一份，不要再复制出第二份。
